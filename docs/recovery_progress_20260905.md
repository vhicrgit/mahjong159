# 2026-09-05 修复与继续训练记录

前置：[独立审计](independent_audit_20260905.md)。原始基线git为`a4f4bba`。
本文件将代码事实、训练实验、牌力评估分开记录，避免再次把失败实现解释成理论上限。

## 本轮修复

- `tools/dagger_train.py`：合法动作由手牌特征或保存的legal_mask确定，独立于
  教师概率支持集；验证在全部合法动作上进行。旧v2/v4数据可从手牌one-hot
  恢复mask，并检查教师答案确实合法。稀疏/硬标签均产生正确的策略梯度。
- 搜索数据的占位value=0不再参与价值回归；新数据可显式指定`value_valid`。
- 训练加入可复现随机种子、稳定的逐数据集切分、有game_id时整局切分、
  小数据集非空训练检查、权重长度检查、严格加载checkpoint。
  原始数据没有game_id，只能按行划分拟合验证，因此牌力必须由全新牌局评估。
- 增加teacher-policy-weight=0和随机合法标签对照；每次训练另存固定预算的
  `_last.pt`，本轮不按验证命中率挑最好epoch来比较。
- `backend/game/bot_driver.py`提供共享自家杠推进。CRN、反事实采集、向量化
  自对弈、DAgger及v4路径补暗杠/补杠；v4 tracker增加对应事件更新。
  v4-v2评估的B臂原本用v31碰杠，与其文档宣称的HV碰杠不同，也已修正。
- `eval_crn`按seed聚类计算SE，保留座位观察数，新增真实净分选项；未到终局
  就触及动作上限时抛错，不把未结束牌局静默算成结果。
- 首胡黄庄时不再从未结算的杠记录生成额外训练奖励。
- `search_teacher`新增首胡多隐藏世界采样，CLI默认重采样+真实净分+HV碰杠。
  同组候选共享世界；temp=0真实贪心续盘。保存逐世界回报、候选对应、
  legal_mask、game_id、value_valid与规则/奖励/模型元数据。
- 多世界采样是**牌数相容的均匀基线**，不是已校准的历史条件后验。
  它不从真实隐藏牌的具体分配/顺序生成答案；但还没有利用对手历史行为推断。
  血战会暴露翻牌等额外历史，暂不支持此采样器；旧v4教师明确仍是fixed-world，
  会打印警告，不能把重复次数当隐藏世界数。
- `filter_teacher`有逐世界回报时按真实配对差计算标准误，保留mask/game_id；
  对旧数据和赢家选择偏差明确警告，不再将阈值筛选包装成独立置信保证。

## 实验A：复用旧教师数据，检验修复后能否恢复收益

运行记录：`logs/audit_recovery_20260905/manifest.json`，含六条完整命令。
产物目录：`models/audit_recovery_20260905/`，没有覆盖线上权重。

共同配置：bc_r2_s3热启动，small，12epoch，batch2048，Adam lr=3e-5，
cosine学习率，vcoef=0，E软标签tau=0.3。训练随机种子71、72各一份。
教师集teach64_conf，三个锚定集k0_nn/k0_nn_r2/k0_nn_fw，权重16/1/1/1。

| 组别 | 教师行策略loss | 其他设置 |
|---|---|---|
| anchor | 乘0 | 教师行仍保留，使批次/更新预算匹配 |
| teacher | 正确硬标签 | 真实合法动作mask |
| random | 在该状态合法动作内随机置换标签 | 负对照，拟合验证仍用原真标签 |

三组均关闭value loss，排除辅助头目标和共享梯度干扰。它们是旧数据的可用性
实验，不是在新完整规则下重新生成的大训练。

### 评估协议

`tools/perf/eval_recovery.py`：被测模型与冻结bc_r2_s3分别面对3×NativeV31，
HV碰杠，完整首胡规则，四座轮换，同seed配对；主指标真实净分，
副指标名次/胡牌率/黄庄率。误差按seed聚类，±为1SE，非95%区间。
逐seed原始矩阵保存在同名npz，可重算不同模型间的配对差。

- 开发集：seed0=206090500，300seed，`dev300.json/.npz`。
- 独立复核：seed0=206100000，3000seed，`confirm3000.json/.npz`。
- 六个模型全部送复核，没有只挑开发集均值最高者。每个模型对应12000个座位
  对局，整个复核共84000局，耗时见JSON。

### 3000seed结果（相对冻结起点）

| 模型 | 真实净分差/局 ± SE | 名次奖励差/局 ± SE |
|---|---:|---:|
| anchor s71 | +0.0453 ± 0.0350 | +0.0196 ± 0.0110 |
| anchor s72 | +0.0479 ± 0.0351 | +0.0208 ± 0.0109 |
| teacher s71 | +0.0083 ± 0.0364 | +0.0006 ± 0.0112 |
| teacher s72 | +0.0274 ± 0.0364 | +0.0077 ± 0.0112 |
| random s71 | -0.0436 ± 0.0395 | -0.0045 ± 0.0123 |
| random s72 | -0.0139 ± 0.0398 | +0.0067 ± 0.0122 |

同一seed内先平均两个训练种子的策略结果，再做配对：

- teacher-anchor：净分-0.02875 ± 0.02793；名次-0.01600 ± 0.00861。
- teacher-random：净分+0.04663 ± 0.03181；名次+0.00308 ± 0.00996。
- anchor-起点：净分+0.04663 ± 0.03475；名次+0.02017 ± 0.01084。

出处：`paired_arm_comparisons.json`。该SE反映新牌局的不确定性，两个训练种子
仍不足以精确估计整个训练算法跨随机种子的变异。

**裁决：修复有效，但旧教师数据没有显示可靠的额外牌力收益。暂不替换冠军。**
这排除了“只修mask就必然涨分”的乐观猜想；不证明新多世界教师无效。

## 实验B：先独立检验新搜索教师，再决定是否蒸馏

先做20状态×4世界的端到端烟测，已完成，含数据保存。
正式小试为8个分片×64状态×32世界×最多3个候选；命令见
`world32_manifest.json`，seed0为207100000起、每分片间隔1000。
首胡、真实净分、HV碰杠，四家续盘策略为bc_r2_s3，temp=0。

判据：每状态前16世界选动作、后16世界检验，再交换两半交叉拟合；
按来源game_id聚合误差。选动作与测收益不能用同一批世界。
工具：`tools/perf/check_world_teacher.py`。
即使通过，也仅说明在该近似世界模型下单动作有平均收益；必须再做真实整局
牌力评估，不能把这个量直接当部署收益。

结果：512状态，来自379个源牌局，8分片全部完成（每分片搜索约4～5分钟）。

| 量 | 结果 |
|---|---:|
| 在选动作的同一批世界上评收益（每状态） | +0.80725分 |
| 独立另一半世界检验（每状态） | -0.05487分 |
| 先按源牌局平均，再统计（每源牌局） | -0.06540 ± 0.04168分 |
| 上项95%正态近似区间 | [-0.14710, +0.01630] |
| 相对原策略改选动作比例 | 63.48% |

出处：`logs/audit_recovery_20260905/world32_crossfit.json`。
每个方向实际上用16个世界选择动作、另16个检验；这不是64/650世界教师的测量。
正负两半共享同一可见状态，已在源牌局层聚合后计误差。

**裁决：当前均匀世界、该采样预算下，教师尚未通过独立收益检查，不将这批
标签投入下一轮正式蒸馏。** 同批argmax收益的大幅虚高被直接量化。
区间包含0，不能宣称真实收益严格为负，更不能再次推论整个搜索路线无效。

## 下一步优先级（尚未执行，不是已取得收益）

1. 学习跨状态共享的动作价值/成对收益，或用短视野rollout加经独立验证的价值
   估计，减少对每个状态单独argmax少数完整rollout的依赖。当前保存的逐世界
   矩阵能作为诊断样本，512状态不足以支持大规模泛化结论。
2. 校准隐藏世界采样：对手历史行为、牌型结构与均匀基线做独立预测验证。
   当前先确认牌数相容/不泄露真实隐藏分配，不能等同后验正确。
3. 按实测成对方差和决策价值分配搜索预算，先在留出的世界验证改进，再扩大
   数据生成；不直接把rolls乘100当作必然解决办法。
4. 扩展碰/杠/过的学习动作空间，建立真人高手错手集和同规则实战验收。
   本轮已补执行机会，但没有把这些规则决策变成神经网络可学习动作。
