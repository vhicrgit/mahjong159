## ⚠️ 重大修正（2026-08-25 晚）：搜索路线证伪，转向 Oracle Guiding

**干净大样本（3000局）复测颠覆了此前判断**:

| 方法 | 大样本干净胜率 | 此前小样本(600-1000局) |
|------|--------------|----------------------|
| v1 规则 | ~27% | — |
| v3 MC搜索(64 rollout) | **27.4%** | 29.4%（假象） |
| v4 混合搜索 | **27.9%** | 31.0%（假象） |
| v5 神经网络 | 28.0% | — |
| Oracle（完美信息作弊） | 48-50% | — |

**结论: 我们能实现的搜索（PIMC/MC 精修）无法超越解析启发式，全卡在 27-28%。**
之前 31%/29.4% 都是小样本上方波动（600局±3.7%）。
→ **"搜索当教师"的 AlphaZero 前提不成立**（搜索教师≈NN学生，蒸馏必退化，
探针实测 28.0%→26.3% 印证）。

**差距的本质是信息，不是策略优化**: 所有非作弊方法卡在 27-28%，只有完美信息
Oracle 到 50%。策略层面已到头，唯一杠杆是信息利用。

### Suphx 式 Oracle Guiding（简化版已试，失败）
- 生成数据时牌墙已知 → Oracle 算完美信息最优决策（48-50%水平）
- 用 **Oracle 决策做标签**，只给 NN **盲打特征**（不含未来/对手手牌）
- 实现: `gen_learner.py --teacher oracle`；数据 `oracle_guiding_100k.npz`
  （Oracle 座位0 得分 mean=2.49, 得分>0 占 46.8% —— 教师标签质量确实高）
- **结果（失败）**: 从 dqn_off_v5(28%) 蒸馏, cql=2.0, 15ep:
  25.5%(训练前) → 23.9(5ep) → 25.5(10ep) → 25.3(15ep)，**无净提升**；
  cql=0.3 对照更差: 25.5 → 24.3 → **20.2%(10ep)** 大退化。
  → 无论强模仿动作(高cql)还是学价值(低cql)都有害。
- **原因（Suphx 早已指出）**: 不能直接模仿 Oracle 动作。Oracle 的决策依赖它
  作弊看到的未来牌墙（如"知道下张摸5万所以留46万搭子"），盲打时无此信息，
  直接模仿 = 注入不可观测信息的噪声/误导。Suphx 正解是**渐进遮蔽**
  （输入先含完美信息, 训练中逐步 dropout 到盲打），非简化版直接映射。

### ★ 核心结构洞察：为什么所有方法卡在 28%
**安康159 只能自摸胡、不能点炮。** 这是根本原因:
- 无"放铳"→ 无防守博弈深度（防守只剩"不喂杠"，v2 已捕捉）
- 游戏本质 = "比谁先自摸"的牌效竞速 + 少量杠分
- 牌效竞速的盲打策略空间本就窄，v1 规则Bot(向听+进张+防喂杠)已接近盲打较优
- 对比日麻: 点炮/立直/一发/振听等丰富攻防 → Suphx 有大提升空间；
  159 规则极简 → 牌效之外几乎无可挖掘的策略深度

**Oracle 的 50% 几乎全部来自"作弊预知自己何时成牌"** —— 纯运气信息,
对盲打完全不可迁移。故盲打上限大概率就在 **28-30%**，我们已接近。

### 仍未排除的提升手段（按预期收益排序，均为"几个点"量级）
1. 真正的渐进 Oracle Guiding（工程量大, Suphx 核心, 但159未来牌墙迁移价值存疑）
2. 特征增强（Suphx/Mortal 用更丰富特征: 每张牌详细历史/听牌型/番种）
3. 对手手牌建模（159无点炮 → 价值低, 优先级最低）

## （以下为原始分析，"搜索当教师"部分已被上方修正取代）

## 一、离线蒸馏的天花板：接近但不完全等于 v4

蒸馏 = 学生模仿 v4 的动作。两个方向的力:
- **下拉**: 模仿有损，学生通常略低于教师（预期 29-30% vs v4 的 31%）
- **上拉**: 我们的损失 = CQL(模仿) + Q回归(学 MC return)。当"模仿教师"与
  "价值最大化"冲突时，价值项能纠正教师的系统性错误（如 v4 搜索近似带来的偏差）

净效果: 学生 ≈ v4 ± 1 点，**不会大幅超越**。指望单次离线蒸馏破 35% 不现实。

## 二、突破 v4 的两个必要机制

### 机制1: 自对弈打破固定数据分布
离线死结: 数据永远来自 v4，模型只见过 v4 制造的局面，学不到"针对比 v4
更强的对手"。自对弈让**当前最强模型**互相对打生成新数据，数据分布始终
跟着当前水平走，而非钉死在 v4。

### 机制2: 搜索作为"策略提升算子"（持续变强的引擎）
纯自对弈 + RL 梯度在麻将（不完美信息 + 高方差）里易退化
——本项目 PPO/AWR/DQN在线 全部退化就是铁证。

AlphaZero 的真正秘诀不是自对弈，而是**每步用搜索改进当前策略**:
```
NN 给策略 π → 搜索前看几步得到更优 π' → 用 π' 训练 NN
→ NN 变强 → 搜索起点更高 → π' 更强 → ...
```
搜索提供的"π' > π"是纯 RL 梯度给不了的稳定提升信号。

## 三、规划的迭代循环（天花板是 Oracle ~50%，非 v4）

```
第0轮(进行中): v4搜索(31%) --蒸馏--> NN₀(~30%, 推理快900倍)
第1轮: NN₀ 给 beam search 排序/剪枝(用 Q 值筛候选、给 rollout 定方向)
       → 相同算力下搜索更深/更准 → v5搜索 > v4
       → 4×v5 自对弈生成数据 --蒸馏--> NN₁ (>30%)
第2轮: NN₁ 引导搜索 → v6 > v5 → ... 正反馈放大
```

每轮"搜索 > 当前NN"的增量就是进化的燃料，NN 变强又抬高下轮搜索起点。

## 四、诚实的边界

- 麻将不完美信息 + 高方差 → 正反馈斜率递减
- 现实预期停在 **35-42%**（远超当前 31%，但摸不到 Oracle 的 50%）
- 对照: Mortal/Suphx 对人类高手的优势也是"几个百分点"量级

## 五、关键工程前提（已就绪）

1. **搜索⇄NN 的接口**: `search_first_discard_detail(counts, future, beam,
   candidates)` 已支持候选限制 —— NN 可先筛 top-k 候选再交给搜索，省算力
2. **CQL 权重 = 模仿强度**（数学上等价于 BC 交叉熵）: 强教师下应上调
   cql_weight（0.5→2.0→5.0），弱教师下无所谓（已解释历史 sweep 平坦）
3. **算力**: 184 核并行自对弈 + 8×H20 训练，一轮迭代 ~3-4 小时可完成
4. **评估**: 座位效应已知，用 `bot_eval` 固定座位0对3×v1，或四座位轮转
